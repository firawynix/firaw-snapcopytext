# Firaw - SnapCopyText 1.1.13

## Alterações

- Cada combinação de Print Screen pode ser configurada separadamente.
- `Print Screen`, `Alt + Print Screen` e `Ctrl + Print Screen` podem abrir região, monitor ou janela.
- Cada combinação ainda pode ser devolvida individualmente ao comportamento original do Windows.
- Configurações existentes continuam usando os modos anteriores: região, monitor e janela.
- A tela principal mostra o modo atualmente associado a cada atalho ativo.
- O manifesto `update.json` foi atualizado para o launcher automático.
- A release é sincronizada com o catálogo do Firawynix Center.
