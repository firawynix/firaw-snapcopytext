# Firaw - SnapCopyText 1.1.14

## Alterações

- As três combinações do perfil Print Screen agora podem ser alteradas pelo usuário.
- Clique no campo e pressione uma combinação com `Ctrl`, `Alt` ou `Shift` + `Print Screen`.
- Exemplo: `Alt + Print Screen` pode ser substituído por `Shift + Print Screen`.
- A combinação anterior deixa de ser interceptada pelo Firaw após salvar.
- Cada combinação mantém sua escolha independente entre região, monitor e janela.
- Combinações repetidas e conflitos com o atalho adicional são bloqueados antes de salvar.
- Configurações antigas continuam com os atalhos `Print Screen`, `Alt + Print Screen` e `Ctrl + Print Screen`.
